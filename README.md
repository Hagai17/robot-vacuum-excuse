Entry for the make.fun bounty [The Robot Vacuum's Best Excuse](https://make.fun/bounties/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

## The entry

> I have cleaned that spot 214 times. It re-dirties within the hour. My map no longer calls it a floor. It calls it a subscription.

## Run

```sh
python3 main.py
```

Prints the entry and writes it to `/output/entry.txt`.

## How it was made

11 candidate excuses were drafted and duel-scored in `candidates.md` against the kit's published judge criteria (tired-homeowner judge: on-topic excuse, laugh size, rootedness in the vacuum's own world — map, clean log, sensors — a clean end turn, and the vacuum's deadpan voice). The winner merges the strongest blame-shift laugh with the machine's own bookkeeping: a count of 214 logged cleans and a map that renamed the floor a subscription.
